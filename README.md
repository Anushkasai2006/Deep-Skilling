# Design Patterns and Software Design Principles Practice

This repository includes hands-on exercises focused on understanding and implementing software design principles and design patterns.

## Exercises

### Exercise 1: Singleton Design Pattern

- Explore the concept of the Singleton Pattern.

- Develop a class that ensures only a single instance exists during the application's lifecycle.

### Exercise 2: Factory Method Design Pattern

- Study the Factory Method Pattern.

- Create and manage object creation through a factory class rather than using direct object instantiation.

## Key Concepts

- Software Design Principles

- Design Patterns

- Object-Oriented Programming (OOP)

## Objective

The main objective of this repository is to strengthen knowledge of software design patterns and principles by implementing them through practical coding exercises. This helps in understanding how these concepts are applied in real-world software development.
